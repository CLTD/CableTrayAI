# 2026-05-29 新提资 S2 分支与 MT 门禁修复记录

## 1. 问题

本次新提资 `1818 S2支架需求汇总20240711 - 副本.xlsx` 的序号 1 在运行时出现：

- `Result validation failed; production publication is blocked: modal_mt_cutoff`
- 新提资方钢截面为空时，局部逻辑仍保留样例方钢宽度，导致托臂截面族、焊缝评定分支和附录 C 输出可能误判。

## 2. 本次确认的 S2 规则

方钢截面外边长是托臂分支和焊缝评定分支的控制量：

- 方钢外边长 `<= 120 mm`：普通托臂分支，托臂截面使用 `50-42 / CAOGANG42DAN`，托臂根部焊缝使用等效应力评定，等效应力系数 `0.526`，附录 C 输出托臂应力云图。
- 方钢外边长 `> 120 mm`：异形钢托臂分支，托臂截面使用 `YIXINGGANG150 / YIXINGGANG150DAN`，附录 C 输出焊缝评定原理，不强制输出托臂应力云图。
- 托盘宽度、层数、单双侧不能单独触发异形钢分支；它们只参与载荷、拓扑和层数参数。

## 3. 已修复

1. 新提资列 I 方钢截面为空时，不再沿用样例 `160 mm` 宽度；先同步当前标准模型截面，例如本次序号 1 使用 `100-100-8`。
2. 删除“托盘宽度 >= 600 mm 触发异形钢托臂”的错误条件；托臂截面族只由方钢外边长决定。
3. 方钢自动选型后，若选中截面外边长跨过 `120 mm` 分界线，会同步替换建模命令流中的主托臂和次托臂 `SECREAD`。
4. 支持自动生成 `HREC` 方钢截面时继续正确替换托臂截面；替换逻辑改为模型中最后两个 `SECREAD`，对应 S2 主托臂和次托臂。
5. `MT` 初始值仍在求解前指定；若 `Mode.oup` 未覆盖 50Hz，正式流程会按 `40/60/80/90/100/120/160/200/240` 递增重算，直到 `Mode.oup` 通过 50Hz 门禁或明确失败。
6. 新提资选择“序号 1”时，按提资表中的序号匹配，不再只按 Excel 物理行号匹配。
