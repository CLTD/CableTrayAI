# 力学室AI工程设计辅助平台范围

> 当前版本已暂停多模块扩展，第一版回到“电缆桥架智能力学分析平台 + 单位内网模型质控”。下文只作为后续可能扩展的历史设计记录，不作为当前部署界面或验收范围。

## 当前定位

平台不再只定位为单一电缆桥架工具，而是力学室的工程设计辅助平台。第一期必须先把“电缆桥架智能计算”做稳，PEPS/管道、图纸识别、规范与历史案例库先以资料检索和模块对话方式接入。

## 前端工作区

1. 电缆桥架智能计算  
   生产可用模块，包含提资上传、反应谱选择、三份命令流、ANSYS 计算、结果提取、评定、图片提取和报告注入。

2. PEPS / 管道建模辅助  
   不需要提资入口，保留基础对话、资料上传和 FRE 校核入口。模型重点检查 FRE、工况、约束、支吊架规则、载荷组合和需要人工确认的问题。模型回答必须带来源，不能直接替代建模校核。

3. 图纸与资料识别  
   不需要提资入口，保留基础对话和资料上传。先做 PDF、CAD/DXF、扫描件和表格资料入口。OCR/CAD 解析结果必须人工确认后才能进入工程计算。

4. 规范与历史案例库  
   不需要提资入口，保留基础对话、资料上传和报告逻辑校核入口。规范、手册、历史报告、命令流、评定 Excel、审查意见统一索引。回答需要返回来源文件和章节/单元格/命令流位置。

不再单独设置“AI 对话助手”作为主模块。每个工作区都有自己的对话入口，后台按模块上下文检索资料。

## 单位内网模型接入

初版不再打包本地大模型权重，优先接单位已部署的内网大模型。

要求：

- 内网可访问，例如 `http://10.x.x.x:port/v1`。
- 最好兼容 OpenAI `/v1/chat/completions`。
- 没有 key 时，`api_key_env` 留空。
- 有 key 时，在部署主机设置环境变量，不写入仓库。

配置文件：

```toml
[provider]
enabled = true
base_url = "http://单位模型服务IP:端口/v1"
model = "单位模型名称"
api_key_env = ""
timeout_seconds = 90
```

网页提供“探测连接”按钮，只发送一句测试文本，不上传工程资料。

## 模块模型选择

普通操作界面不展示 DeepSeek、千问等候选模型和评分细节，只显示每个模块当前采用的大模型。后台可以按模块做“模型竞聘”：

- 电缆桥架智能计算：重点比运行质控、错误归因、source_ref 边界和后处理异常识别。
- PEPS / 管道建模辅助：重点比 FRE、工况、约束、支吊架规则解释和代码片段审查。
- 图纸与资料识别：重点比 PDF/CAD/DXF/扫描件识别后的结构化解释能力；识别结果必须人工确认。
- 规范与历史案例库：重点比规范引用、历史案例归纳和来源保持能力。

配置示例见 `config/ai.module_models.example.json`。正式部署时可复制为 `config/ai.module_models.json`，只发布 `selected_model` 给网页端。

## 资料自主归库

PEPS/管道、图纸识别、规范与历史案例三个模块上传资料后，平台会调用单位内网模型判断建议归属库。模型不可直接移动或覆盖资料，只输出建议：

- 建议资料库；
- 判断依据；
- 风险；
- 是否需要人工确认。

若单位模型暂未启用，系统用固定关键词规则做初筛，正式入库仍需人工确认。

## 权威边界

大模型可以做：

- 运行状态解释；
- 错误归因；
- 资料检索；
- 命令流解释；
- 结果异常提示；
- 错误备忘整理；
- PEPS/FRE/规范问答。

大模型不得替代：

- ANSYS 真实计算；
- Excel 权威评定；
- 确定性 Python 公式；
- `result_validation.json`；
- 报告注入审计；
- 人工工程审核。

## 14 人共用策略

为避免 14 人同时使用时等待过长：

- 计算任务走队列；
- 模型问答先走检索和缓存，再调用模型；
- 电缆桥架正式计算不依赖模型；
- 单位模型不可用时，平台退回固定工程规则，不阻断主流程。
