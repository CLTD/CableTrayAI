# 方钢截面与附录C模式逻辑

## 生产规则

1. 钢平台：必须采用静力法。
2. 非钢平台：必须采用反应谱法。
3. 方钢外边长 `<= 120mm`：附录C采用托臂应力云图模式，输出 `TB*`、`TD*`。这包含 `120*120*6`、`120*120*8`、`120*120*10`。同时托臂根部焊缝评定仍必须按等效应力表格执行，等效应力系数为 `0.526`。
4. 方钢外边长 `> 120mm`：附录C采用焊缝评定原理模式，不输出托臂应力云图；托臂根部焊缝按焊缝评定原理展示。
5. 方钢截面未知时，先完成候选 `*.SECT` 自动选型，再决定附录C模式。

## 理解

这个规则不是“报告章节长什么样”，而是焊缝/托臂评定路径不同：

- `100` 与 `120` 系列方钢时，托臂根部局部应力云图是校核输入的一部分，需要按托臂集合提取应力云图；但这不取消焊缝评定，托臂根部焊缝应以 `TMAXBEAMSTRESS.LIS / 0.526` 换算等效应力并输出 `表6-2-1 托臂根部焊缝评定结果（应力比）`。
- 方钢外边长大于 `120mm` 时，托臂根部先输出 `表6-2 托臂根部所受载荷`，再按焊缝有效焊喉、焊缝截面几何、剪应力和等效应力输出 `表6-3 托臂根部焊缝评定结果（应力比）`；附录C应展示焊缝评定原理而不是托臂应力云图。
- 托盘-托臂连接螺栓载荷仍然按结构对象计算；托臂根部焊缝分支不能把 `<=120mm` 的 `TMAX/0.526` 等效应力路径与 `>120mm` 的 `HF-FORCE` 载荷路径混用。

## 外部资料核对

- GB 50017-2017 的术语包含钢材拉压弯强度、剪切强度、螺栓强度、对接焊缝和角焊缝强度等设计值，说明焊缝评定不是简单把母材梁单元应力图直接等同为焊缝结论：<https://www.codeofchina.com/standard/GB50017-2017.html>
- IDEA StatiCa 对 GB 50017 角焊缝的说明中，角焊缝按有效截面上的法向/剪向应力组合进行强度验算；全熔透对接焊缝则可按母材强度考虑：<https://www.ideastatica.com/support-center/check-of-welds-according-to-chinese-standard>

## 源冲突处理

历史报告和提资核对后，当前样例规律为：

- `100*100*6`、`100*100*8` -> 托臂应力云图。
- `120*120*6`、`120*120*8`、`120*120*10` -> 托臂应力云图。
- `>120mm` 的方钢截面 -> 焊缝评定原理。当前历史资料里有 `140*140*8`、`160*160*8`。
