# Report Template Finalization

Production report auditing checks:

- required sections are present
- tables are mapped to `result.json` or `excel_evaluation_results.json`
- figures are mapped to `figures_manifest.json`
- formal conclusions are blocked for mock or dry-run data
- unconfirmed formulas require successful Excel authoritative evaluation
- maximum ratio and conclusion remain consistent

Detailed visual polishing of `templates/report/s2_report_template.docx` remains a human review task before controlled deployment.
