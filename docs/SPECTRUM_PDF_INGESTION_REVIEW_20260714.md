# 土建反应谱 PDF 数据识别评审（2026-07-14）

## 1. 评审结论

- 当前正式能力是读取经过人工确认的 Excel/XLSM 楼层谱工作簿，并按单位工作簿 VBA 的数据组织和包络算法生成 ANSYS 谱命令。
- 当前未实现从土建专业 PDF 识别“厂房/区域、标高、方向、阻尼比、频率、加速度”并写入谱工作簿的数据链路。PDF 不能直接作为正式谱输入。
- 本地资料中未检出可作为开发和回归基准的土建专业反应谱 PDF，因此不得宣称任意 PDF 已可自动进入正式计算。
- PDF 识别可实现，但必须输出候选数据并经过来源定位、结构完整性校核和人工确认，不能由 OCR 或语言模型补造缺失数值。

## 2. 已核实的 VBA 等价实现

单位工作簿 VBA 已只读提取并与下列当前代码逐步对照：

- `core/spectra/static_coefficients.py`：分段谱数据、厂房页匹配、频率对数插值基础函数。
- `core/spectra/workbook_envelope.py`：标高线性插值、X/Y/Z 分方向谱、X/Y 水平包络、多输入包络、八组精度控制和简化点生成。
- `core/spectra/response_spectrum_writer.py`：SL-1(XY)、SL-1(Z)、SL-2(XY)、SL-2(Z) 四组 ANSYS Format 数据及 21 至 26 载荷步命令。

已核实算法关系：

1. 标高位于两个源标高之间时，加速度按标高线性插值。
2. 不同源谱频率点合并时，加速度按频率的对数坐标插值。
3. X、Y 先分别形成谱，再在统一频率点上取水平包络；Z 独立处理。
4. 最粗、最细和自定义控制来自工作簿精度控制页，不是固定点数。
5. ANSYS 输出按三位小数写入，四组谱均保留 100 Hz 末点供 ZPA 使用。

现有源工作簿活动 M 列保存的是两个标高输入的包络，而正式任务写入器以单个任务厂房和标高为输入。当前 M 列解析器只把单输入活动块作为任务级校准源，多输入活动块不会错误套用到单输入任务。该限制需要在后续多输入谱功能中单独扩展，不能放宽匹配条件。

## 3. 本轮准确性增强

`core/spectra/response_spectrum_writer.py` 新增正式谱曲线完整性门禁，写入 APDL 前逐组检查：

- 频率和加速度点数一致且不少于两个；
- 频率为有限正数并严格递增；
- 加速度为有限非负数且不得全部为零；
- 最后一个频率点必须为 100 Hz。

本轮未修改标高插值、频率插值、包络、阻尼比选择和精度控制算法。

## 4. PDF 数据识别的正确目标链路

目标不是把 PDF 文件简单转换成 Excel，而是：

`土建谱 PDF -> 页面/表格定位 -> 数值候选数据 -> 规范化谱数据集 -> 人工确认 -> Excel/XLSM 谱库 -> VBA 等价包络 -> ANSYS 谱命令`

候选数据至少包含：

- 项目和谱文件版本；
- 厂房或区域；
- 标高及单位；
- SL-1/SL-2 或等效等级；
- X/Y/Z 方向；
- 阻尼比；
- 频率及单位；
- 加速度及单位；
- PDF 页码、表格区域、原始文本和文件哈希。

PDF 识别器应按三种来源分支：文本表格、矢量图线、扫描图像。文本表格可以直接抽取单元格；矢量曲线必须识别坐标轴和数据点；扫描图像需要 OCR 与表格/曲线复核。三种分支均只能生成候选数据。

## 5. 正式进入计算前的门禁

1. 同一厂房、标高、等级、方向和阻尼比组合不得重复或冲突。
2. 正式需要的 X/Y/Z、SL-1/SL-2 和目标阻尼比分支必须完整。
3. 频率必须严格递增，单位必须明确，加速度不得由空单元自动补零。
4. 数据范围和 100 Hz 末点必须满足单位谱格式要求；缺失时阻断，不外推补造。
5. 每个数值必须能反查 PDF 页码和区域。
6. 人工确认后才写入项目谱库，并记录 PDF、规范化数据集和 Excel 文件哈希。
7. 由现有 VBA 等价算法生成四组 ANSYS 谱后，与单位批准的工作簿输出逐点比较；频率或加速度三位小数不一致时阻断正式求解。

## 6. 后续实施前置材料

- 至少提供一份可公开用于开发的真实土建谱 PDF；最好同时提供其人工录入后的批准 Excel/XLSM。
- 明确 PDF 中频率、周期、加速度、速度或位移谱的单位和坐标含义。
- 明确新项目 Excel 谱库模板是沿用当前分段工作簿，还是采用项目无关的规范化数据表后再导出当前格式。
- 建立至少三类 golden tests：文本表格 PDF、矢量曲线 PDF、扫描 PDF；每类逐点对照批准 Excel，未达到零差异不得用于正式计算。

## 7. 后续界面与训练闭环

- 在反应谱资料区增加“识别 PDF 并生成谱 Excel”按钮，但该按钮初期只生成候选工作簿，不直接替换操作员选定的正式谱文件。
- 候选工作簿同时输出识别明细、PDF 页码/区域、原始文本或曲线点、单位归一化结果、冲突项和待确认项；无法定位来源的数值不得写入正式数据页。
- 每个新项目优先收集成对资料：土建专业原始 PDF 与人工确认后的批准 Excel/XLSM。两者作为训练/规则改进样本和 golden regression 基准，不直接作为语言模型记忆中的无来源数值。
- 人工确认后，系统保存 PDF 哈希、候选数据集哈希、批准工作簿哈希和生成器版本；同一输入重复生成应得到一致结果。
- 当不同国产模型或 OCR 引擎给出不同候选结果时，由确定性结构校核和逐点基准比较决定是否通过，正式 ANSYS 谱命令仍由现有 VBA 等价算法生成。
